# TopK weight BF16 / FP32：统一 FP32 基准的精度对照

本报告用于训练协作分支的专项复核；**本报告及配套数据不进入 main 或 lueelu/DeepEP 的正式提交**。

日期：2026-11-06。范围：**EP8、每源 M4096、H7168、F3072、TopK6、每 rank 4 专家、save=bf16、clipping=10**，
balanced routing、random 数据、seed=20260825、路由缩放系数 1。

这组数据中，FP32 p 相比 BF16 p，五项输出的**平均相对误差和 ATK RMS 字段在 8 个 rank 上均下降**。
RMS 逐 rank 降幅的中位数为：Y 8.68%、dX 4.42%、dp 12.77%、dW1 4.72%、dW2 10.48%。
最大相对误差没有逐项、逐 rank 全部改善，见后表。

## 共同真值和评价类型

令原始路由概率为 FP32 `p32`，共同真值为：

```text
G = CPU_FP64(X, ids, p32, W1, W2, dY)
BF16 路径：MegaMoE(X, ids, BF16(p32), W1, W2, dY) 对 G
FP32 路径：MegaMoE(X, ids, p32,       W1, W2, dY) 对 G
```

“CPU TopK weight FP32”为参考输入的精度，CPU 数学计算仍使用既有 FP64 真值实现。
X、dY、W1、W2、路由和 clipping 均按冻结输入保持一致，未改变实际算子或 ATK 门限。

其他四项输出的实际类型与评价类型均为 BF16。dp 的实际返回仍跟随输入 p：BF16 p 返回 BF16，FP32 p 返回 FP32。
为统一 dp 评价口径，新采 BF16 dp **只在误差评价前无损 `.float()`**，BigOp dp 同样处理；与旧 FP32 dp 的 FP32 评价对齐。
该转换不会改变任何 BF16 dp 数值，也不改变算子的返回接口或本次原 ATK 报告。

采用此步骤的原因：本轮 CPU 黑盒检查确认，即使 actual 数值完全相同，仅 BF16/FP32 类型不同，
私有 ATK 的部分误差字段也会改变。例如同一 wide 样本的 RMS 为 1.85305267 与 1.63640219，
单纯指标类型效应就可产生约 11.69% 的字段差异。
因此不能直接把此前不同评价类型的 dp 字段相除当精度收益；本表使用追加的统一 FP32 评价结果。

例如 dX 的最大相对误差只有 4/8 rank 改善，最差 rank 增加约 14.50%；它的平均及 RMS 指标仍在所有 rank 上改善。

## 本轮复用与新增内容

- FP32 侧复用已有 `full_ep8_m4096_h7168_fp32full` 的 8 份原始 rank 报告，没有重跑 FP32 MegaMoE。
- 新增 BF16 MegaMoE 一组完整前反向。由于旧成功用例的 CPU golden 已删除，本轮重建一次 FP32 p 的 CPU 真值，
  每 rank 仅调用一次原 CPU reference；只替换 CPU reference 接收的 p，实际 fused/BigOp 仍接收 BF16 p。
- 冻结生成器分别生成 p32 与 BF16(p32)，实际核对所有非 p 输入哈希一致，以及 BF16 p 等于 p32 的 BF16 舍入。
  全局 p、X、dY、ids 等哈希在 8 rank 一致；权重按对应专家 rank 的固定种子生成。
- 旧 FP32 实际输入和 golden 张量未保留，旧侧同输入依据为同一冻结生成器、配置、seed 和相同 CPU 输入生产库。
  本轮没有对不存在的旧 golden 张量作逐位核对的声明。
- 新 BF16 的 8 rank 原 ATK/counts 检查通过、runner 退出码 0；比较结果保留全部逐 rank 数字。
  通过测试本身不作为“精度提升”的判据，主表只由两侧实际误差字段计算。

## 数值含义

Y、dX、dW1、dW2 的对照反映保留 p 的 FP32 有效位后相对同一个 p32 数学真值的误差变化。
令 `h = SiLU(gate) * up` 表示按当前 clipping 规则处理后、尚未乘 p 的激活，dp 的理想公式为 `sum_F(dHp * h)`。
固定 X/W/路由/dY 时，该真值不依赖 p 的数值；该项主要用于观察保留 FP32 dp 返回精度的作用。
不能把 dp 的全部收益解释为前向 p 输入有效位的收益。

本结论只覆盖上述一组 shape、seed 和 save=bf16，不推断其他分布、保存格式、多机、训练 loss 或整网收敛。
